Instrument user manual
======================

This manual describes CLASSI as a complete telescope instrument. It follows the
lifecycle of a spectroscopic observation rather than repository boundaries and
is intended for observers, operators, instrument scientists, and people reducing
CLASSI data.

Begin with the system overview. The later chapters cover observation planning,
optional detector-level simulation, instrument operation, reduction, and the
full observation lifecycle. Package pages are implementation references and are
linked where they add useful detail.

.. note::

   CLASSI is still being characterized. Values that depend on the as-built
   alignment, focus, throughput, or observing environment should be marked as
   measured only after commissioning data establish them. Until then, catalog
   specifications and model predictions are planning inputs rather than final
   instrument performance guarantees.
